# 尾巴图片工坊 TrimTail

浏览器里的本地图片处理工具：裁剪、旋转、压缩、转换格式和背景处理。图片在你的浏览器中处理，不上传到服务器。

**在线使用：** <https://FIERsity.github.io/TrimTail/>

**版本：** `0.3.0`

**主站：** <https://tools.red-pandas.com/>

## 功能

### 调整图片

- 自由裁剪或固定比例裁剪：1:1、16:9、9:16、4:3、3:4
- 顺时针 / 逆时针旋转
- 水平 / 垂直翻转
- 拖动裁剪框和四角手柄调整范围
- 方向键微调裁剪框位置
- 撤销 / 恢复编辑操作

### 背景处理

背景处理分为三个顶层状态：

- **原图**：保留原始背景
- **去背景**：生成透明背景
- **换纯色底**：沿用当前去背景蒙版，只改变透明区域的底色

去背景提供三种策略：

- **自动去背景（外沿）**：适合连接到图片边缘的纯色或接近纯色背景
- **按颜色去除（全图）**：通过取色移除整张图片中的相近颜色，也能处理主体内部的背景区域
- **本地模型（人像）**：使用浏览器本地运行的 MODNet 人像模型，首次使用时按需下载并缓存

按颜色去除支持最多四个取样颜色和可调颜色容差。取色时，点击“添加颜色”或“取色”，再在画布上点击背景；按 `Esc` 可以取消取色。

### 输出图片

- WebP、JPEG、PNG
- 按质量导出
- 压到目标大小：通过质量和分辨率调整接近目标
- JPEG 不支持透明通道；当透明去背景结果输出为 JPEG 时，透明区域会自动铺白
- 下载栏位于编辑器底部，处理摘要会显示当前应用的主要操作

### 支持格式和限制

- 常见输入：PNG、JPG/JPEG、WebP、GIF、BMP、AVIF、TIFF；实际能否读取取决于当前浏览器
- GIF 当前按静态首帧处理，不保留动画
- 超过 6400 万像素的图片会被拒绝，以避免浏览器内存压力
- 本地模型主要针对人像，不是通用物体抠图模型
- 模型首次使用大约需要下载 23 MB 模型和约 23 MB 浏览器运行组件，之后会使用浏览器缓存

## 隐私

普通图片处理在浏览器本地完成，图片内容不会上传。

选择本地模型时，浏览器会从 Hugging Face 下载模型文件；下载的是模型资源，不是你的图片。模型文件会缓存在浏览器中，可以在模型面板中清除。

## 本地开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev      # 启动开发服务器
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```
